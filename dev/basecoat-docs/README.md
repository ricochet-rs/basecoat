# basecoat-docs

A local mirror of the Basecoat documentation, one markdown file per page,
fetched from `https://basecoatui.com/<path>.md`.

This is reference data for building the wrappers. Do not read `basecoat-css`
source instead. Refresh a page with:

```
curl -sL -o components-name.md https://basecoatui.com/components/<name>.md
```
